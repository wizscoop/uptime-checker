# Uptime Checker

A lightweight Python CLI tool that checks website availability, response codes, and latency.

## Setup
1. Clone the repo: `git clone <repo-url>`
2. Create and activate a venv: `python -m venv .venv && .\.venv\Scripts\Activate.ps1`
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `python main.py`
